## 🛠️ Troubleshooting

### "Page not loading"
1. Check internet connection
2. Hard refresh: Swipe down → pull to refresh
3. Clear cache:
   - iOS: Settings → Safari → Clear History & Website Data
   - Android: Menu → Settings → Clear Browsing Data
4. Try different browser

### "Charts not showing"
1. Wait 2-3 seconds for page to fully load
2. Scroll down and back up
3. Hard refresh (as above)
4. Update your browser app

### "Data looks outdated"
- Data is from 07-MAY-2026
- Check GitHub repo for updated versions
- No real-time updates (educational version)

### "Signals not making sense"
- Verify correct stock selected
- Check expiry date
- Review strategy guide in sidebar
- Read disclaimer: educational purpose only
